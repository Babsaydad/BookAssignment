# BookAssignment
An MVC model showing a list of books which can be viewed by everyone but can only be edited, created or deleted by admin.

If you are a new user, kindly create an account by clicking on the "Register" button at the top right of the page.

If you are not a new user, click on "Login" to view your preferred book details.
